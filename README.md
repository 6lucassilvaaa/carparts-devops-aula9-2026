# Carparts — prática DevOps da Aula 9

Laboratório didático novo, criado com assistência de IA. Não representa o repositório real ou o histórico operacional de uma empresa. O HTML original usa “Aula 08” no cabeçalho; a atividade no Classroom está como Aula 9.

## Execução

Requer Node.js 22 ou posterior e Git. Execute npm test. Não há instalação de dependências. O código mínimo de estoque permite verificar regras reais e reproduzir regressões no laboratório Git.

## Entrega

- E1: docs/E1-diagnostico.md e evidencias/diagnostico-inicial.txt.
- E2: CONTRIBUTING.md.
- E3: .github/CODEOWNERS, evidencias/protecao-main.json e docs/E3-protecao.md.
- E4: .github/workflows/ci.yml, docs/E4-metodo.md, docs/E4-resultados.md e artefatos reais do Actions.
- E5: scripts/laboratorio.mjs, docs/E5-laboratorio.md e evidencias/laboratorio-git.txt.
- E6: docs/E6-parecer.md.
- Plano para transcrever nos seis campos da prática: docs/planos-HTML.txt. Não altera o questionário.

## Limitações a conferir antes do envio

A merge queue depende de organização elegível; conta pessoal não é compatível. PR escrito por agente fica aberto para revisão humana, sem autoaprovação ou integração. É necessário revisor humano distinto do autor e com escrita no repositório. Os prints reais das configurações estão em evidencias/protecao-main.png e evidencias/protecao-main-checks.png. JSON de configuração é evidência técnica complementar. As evidências de revisão devem ser acrescentadas quando houver revisão humana.
